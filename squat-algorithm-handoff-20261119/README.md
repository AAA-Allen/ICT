CLI 在 `biomechanics.dual_analysis` 输出骨架规则候选摘要与运动学解释。按关键点覆盖率筛选后，提供幅度、完整动作节奏、双膝协同及侧面躯干倾斜参考；未设置未经验证的损伤或判错阈值。两路共用 MediaPipe 骨架，不视为独立传感器，不互相投票。未注明机位时可用三维运动学仍能形成描述，具体问题检测继续遵守原视角要求。
