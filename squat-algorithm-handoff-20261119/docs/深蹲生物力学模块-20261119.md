# 深蹲生物力学模块与开发接入

本轮实现生物力学中的运动学分析：复用现有 MediaPipe 骨架，增加角度、位移、左右差异与动作时间的描述。模块版本为 `squat-biomechanics-kinematics-v1`。当前属于开发验证功能，尚未完成与运动捕捉真值的精度对照，也尚未证明能提高现有问题标签的识别率。

## 分析内容

| 指标 | 输出字段 | 使用条件与含义 |
| --- | --- | --- |
| 左右膝屈曲角 | `left_knee_flexion_deg`、`right_knee_flexion_deg` | 模型估计三维髋膝踝；站直约 0° |
| 左右躯干与大腿夹角变化 | `left_trunk_thigh_angle_deg`、`right_trunk_thigh_angle_deg` | 肩髋膝三点，以伸直共线为 0°；肩部姿势影响数值，不能视为精确的解剖学髋角 |
| 左右膝角差 | `bilateral_knee_difference_deg` | 同帧双膝角绝对差，供观察不对称变化；不直接判错 |
| 躯干、小腿倾斜 | `trunk_image_tilt_deg`、`left_shank_image_tilt_deg`、`right_shank_image_tilt_deg` | 仅声明侧面机位时输出；按视频宽高恢复像素比例，相对图像竖直方向计算 |
| 髋部下降 | `hip_descent_leg_ratio` | 髋相对双踝的竖直下降量除以站姿参考投影腿长；为二维比值，无真实距离单位 |
| 动作节奏 | 每次动作的 `descent_to_bottom_sec`、`bottom_to_end_sec`、`active_ascent_sec` | 继承阶段边界；后者在检测到最低点停留时扣除停留尾段。片段不完整时同时查看 `boundary_status` |

每项指标提供有效帧数、覆盖率、中位数和 5%/95% 分位数。至少需要 3 个有效帧且覆盖所在片段的一半，才提供汇总值。缺失值为 `null`，状态为 `unknown`；不能将其解释为角度为零。

髋部下降参考要求相邻两帧双膝均不超过 25°、四个角度的范围不超过 8°、间隔不超过 0.16 秒且双腿可见。找不到参考时，该指标保持未知。相机移动、人物转向、透视和定位抖动会影响结果；当前模块没有验证相机是否固定或声明的视角是否正确。模型三维角度同样受遮挡和估计误差影响，单个数值不能独立证明异常。

## 开发接口

现有 CLI 自动增加顶层 `biomechanics`，原有 `guidance` 和标签字段保留。

```powershell
python -X utf8 scripts/squat_offline_api.py --video "C:\uploads\input.mp4" --model models/pose_landmarker_lite.task --action normal_squat --camera-view side --all-labels --knee-mode high-recall --output "C:\results\new-result.json"
```

输出文件必须尚不存在，父目录提前创建。继续按离线异步任务接入。

- `biomechanics.metrics`：视频级指标汇总。
- `biomechanics.cycles`：每次深蹲的阶段时间和指标汇总。
- `biomechanics.frames`：逐帧时间 `t` 与各指标值，时间单位秒，便于画曲线与定位片段。
- `biomechanics.standing_reference`：髋部下降所用的参考时间和内部像素尺度；没有参考时为 `null`。
- `biomechanics.validation`：目前为 `descriptive_development_only`。

正面视频仍可运行；侧面专用倾斜字段会返回 `requires_declared_side_view`。原膝内移规则的观察窗口保持为下蹲后半段、起身最初四分之一，未以新角度值替代原规则。节奏与角度只补充可解释证据，尚未启用新的自动判错阈值。

Agent 可先描述：第几次动作、对应时间、可用指标的变化，再结合问题候选和用户目标生成提示；不要仅因左右存在角差或躯干前倾就输出错误。对疼痛、不适的追问继续走原有流程。

## 验证与后续

增加合成测试覆盖 0°/90°角度、关键点缺失、退化骨段、侧面条件、空帧序列和含停留的不完整周期。另对现有 10 条典型视频缓存运行检查，保存 `eval/squat_biomechanics_v1_20261119/示范分析.json`；这些为开发样例，不作为独立准确率。

下一轮优先用固定侧面机位自录视频，对膝角、阶段时间与倾斜趋势人工复核；按人物留出测试视频，再决定是否将指标作为规则或模型的新特征。

## 能力范围与方法依据

MediaPipe 输出的是图像坐标及模型估计的三维世界坐标，详见 [Google Pose Landmarker 文档](https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker)。本模块没有地面反作用力、个体身体参数和经校准的动力学模型，因此关节受力、关节力矩、肌肉激活及损伤概率列入 `unavailable`。后续如果需要动力学分析，应补充测量和验证；参见 [OpenSim 逆动力学说明](https://opensimconfluence.atlassian.net/wiki/spaces/OpenSim/pages/53090063/Getting%2BStarted%2Bwith%2BInverse%2BDynamics)。
