# 深蹲膝内移算法交付版

当前规则版本为 `knee-inward-review-v3`。离线分析单人正面深蹲视频，输出膝内移候选、待复核片段和对应时间、侧别、证据，供比赛演示和人工复核。

## 运行

在解压目录运行以下命令。依赖安装和模型下载各执行一次。已有同一版本模型时，可直接使用它的文件路径。

```powershell
python -m pip install -r requirements-squat-skeleton.txt
New-Item -ItemType Directory -Path models -Force
Invoke-WebRequest -Uri 'https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_lite/float16/1/pose_landmarker_lite.task' -OutFile 'models/pose_landmarker_lite.task'
python scripts/squat_offline_api.py --video 'C:\path\input.mp4' --model models/pose_landmarker_lite.task --action normal_squat --camera-view front --output analysis.json
```

模型是 Google MediaPipe Pose Landmarker Lite。验证使用的 SHA-256 为 `59929e1d1ee95287735ddd833b19cf4ac46d29bc7afddbbf6753c459690d574a`。[Google 模型说明](https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker#models)

输出路径需为新文件。不传 `--output` 时，结果写到标准输出。可通过 `--action` 指定 `normal_squat`、`wide_squat` 或 `narrow_squat`。现有示范比对和相似视频功能可分别通过 `--reference-registry` 和 `--run` 启用。骨架默认按约 10 帧/秒提取，视角由调用方提供。

## 接口

从 `guidance.observations` 取 `type == "knee_inward"` 的记录。其 `status` 决定显示方式。

| 状态 | 含义 | 展示 |
| --- | --- | --- |
| `candidate` | 膝中心相对个人站姿持续向内移动 | 从 `events` 显示候选时段 |
| `review_required` | 观察到短时明显的水平内移，或宽距起身时双膝同步变化 | 从 `review_events` 显示待复核时段 |
| `unknown` | 视角不适合、轨迹或参照不足，或可分析片段未触发 | 显示 `reason`，可用 `reason_code` 细分 |

同一视频可同时有 `events` 和 `review_events`。事件包含 `side`、`phase`、`start_sec`、`end_sec` 和 `evidence`。时间单位为秒，左右以人物自身为准。`cycle_index` 从 1 开始，对应 `guidance.cycles`。两个候选列表均用于复核，膝内移的 `advice` 为 `null`。主观反馈问答仍由 `guidance.subjective_feedback` 提供。

终版测量膝中心在图像水平轴上相对髋、踝的移动。静态站姿里的膝盖位置作为个人参照。短时复核路径会检查连续骨架、脚踝稳定性、位移持续性及双侧差异。腿部连线倾斜本身不足以触发。短时阈值为可见髋宽的 0.28 倍，另设 4 像素下限。阈值是在 Part1 开发阶段选定的。

下蹲达到一半深度后开始筛查膝内移。起身只筛查离开最低点后的前四分之一，有明确最低点停留时从停留结束算起。检测窗口按每次动作的膝屈曲变化估算，髋部恢复分段或膝角证据不足时可用髋部相对脚踝的竖直变化。输出的 `analysis_windows_sec` 记录每次动作可定位的 `down` 和 `up` 检测窗口，时间单位为秒。站姿可供计算个人参照。

## 高召回模式

当前工作区的分析入口加上 `--knee-mode high-recall` 即可启用 `knee-inward-recall-v4`。它同时检查早期和局部参照，允许较短的有效水平位移片段进入候选，应用相同的检测窗口。

同一批 366 条 Part1 视频上，起身前四分之一规则在 34 条人工阳性中触发 13 条，在 323 条人工阴性中触发 42 条。上一版起身前半段规则对应为 20 条和 96 条。人工标签来自原复核口径，视频级结果用于对照。检测窗口内的召回率需用对应时段的人工标注评估。
