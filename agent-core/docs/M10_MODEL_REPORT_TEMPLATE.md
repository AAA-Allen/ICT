# M10 真实模型复查记录模板

本文件是人工复查模板，不是已完成的验收结果。自动生成的 `report.json` 和持久运行文件为执行事实来源。

- 执行日期、报告目录：待填写
- 模式：必须为 real；当前真实模型状态：未执行 / 已执行
- 输入版本及 SHA-256：从报告复制
- 源码 commit / 工作区修改状态：从报告复制
- 配置模型名：从报告复制；别名实际版本未知时明确写未知
- 服务端默认生成参数：未记录的参数不得推测为温度 0 或其他值
- 重复次数、有效运行数、错误运行数：待填写

| 检查面 | 判据 | 结果与证据路径 |
| --- | --- | --- |
| 框架执行 | 权限、额度、调用、审批及持久化检查通过 | 待填写 |
| 资料审阅 | ready 仅用于明确存在回滚步骤的资料；引文可逐字核对 | 待填写 |
| 任务分流 | 类别符合固定预期；负责人来自目录工具；落盘记录与运行结果一致；拒绝不写入 | 待填写 |
| 重启恢复 | 模型和读取不重复，分配副作用仅一次 | 待填写 |
| 模型稳定性 | 比较重复运行的终态、原因码和核心业务字段；不以措辞一致代替正确 | 待填写 |
| usage | 记录真实返回值和覆盖率；未知不填零、不估算费用 | 待填写 |

如结构合法但结论错误，保留框架执行通过与任务失败两个结论。若配置缺失、服务不可达或没有有效模型回复，明确记录未执行或失败原因，不把本机 HTTP 替身的测试计入真实模型效果。

schema_version 2 的错误行保留已观察到的调用与可用证据。用例异常为 FAIL；审计证据不可用时完成回复数为 null，应复查原因，不能按零次调用或完整模型验收处理。

此记录不包含 API key、Authorization、含凭证 URL、真实账号或私有资料。
