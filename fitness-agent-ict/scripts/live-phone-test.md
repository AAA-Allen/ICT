# 手机实时深蹲测试

手机和电脑连接同一个允许设备互访的 Wi-Fi。Windows 使用 OpenSSL 和已安装前端依赖启动 HTTPS 预览。

```powershell
.\scripts\start-live-phone.ps1 -Address <电脑的 Wi-Fi IPv4>
```

把脚本打印的 `ICT2-Phone-Test-CA.cer` 复制到测试手机。只复制 `.cer`，私钥留在电脑。Android 可在系统安全设置里安装 CA 证书。iPhone 先安装下载的证书描述文件，再在「设置 → 通用 → 关于本机 → 证书信任设置」启用该证书的完全信任。测试完可移除证书。

用手机的 Safari 或 Chrome 打开脚本打印的 HTTPS 地址，允许摄像头权限。电脑端也可以通过本机开发服务的 `/live` 验证。手机 HTTPS 预览只提供静态页面，实时推理不需要 Java 或 Python 服务。

在准备页开启摄像头。固定手机并正对镜头站直，等「取景就绪」后点击「开始训练」。连续做 5 次深蹲，每次站回去核对是否只加一次，然后试一次腿部出画。点「结束本组」进入总结页，查看逐次下降及上升时间和膝内移复核结果。记录设备、浏览器、实际计数、提醒时机和遮挡后的恢复情况。「检测详情」里的毫秒数是平均单帧计算时间，端到端提示延迟需要单独测量。

若手机连接超时，先查两台设备是否在同一网段，以及电脑防火墙或 Wi-Fi 客户端隔离是否阻止了 5443 端口的设备间通信。
